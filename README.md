# NLP Lab — Text Processing and Naive Bayes

## Цель работы
Реализовать основные этапы обработки текста без использования готовых библиотек.

## Реализовано

### Предобработка текста
- приведение к нижнему регистру
- удаление пунктуации
- токенизация
- удаление стоп-слов

### Векторизация текста
Реализованы три модели:
- Binary Bag of Words
- Count Bag of Words
- TF-IDF

### Классификация текста
Реализован алгоритм Naive Bayes с Laplace smoothing.

### Регулярные выражения
Написаны regex для заданных языков.
